Część 2

Modele, migracje i ORM w shell

Od listy w hello.py do modeli

Jeden specjalista może mieć kilka specjalizacji, a jedna specjalizacja wielu specjalistów (wiele-do-wielu):

Specialization
id (auto)
name (unikalna nazwa)

M : N
ManyToManyField

Specialist
id (auto)
first_name, last_name
bio, mode, price
specializations

booking/models.py


from django.db import models


class Specialization(models.Model):
    name = models.CharField(max_length=100, unique=True)

    def __str__(self) -> str:
        return self.name


class Specialist(models.Model):
    MODE_CHOICES = [
        ("online", "Online"),
        ("stacjonarnie", "Stacjonarnie"),
        ("hybrydowo", "Hybrydowo"),
    ]

    first_name = models.CharField(max_length=50)
    last_name = models.CharField(max_length=50)
    bio = models.TextField(blank=True)
    mode = models.CharField(max_length=20, choices=MODE_CHOICES, default="online")
    price = models.PositiveIntegerField(default=180)
    specializations = models.ManyToManyField(
        Specialization, related_name="specialists", blank=True
    )

    def __str__(self) -> str:
        return f"{self.first_name} {self.last_name}"

Cykl migracji: 2 kroki

1. makemigrations
porównuje models.py i tworzy przepis w booking/migrations/0001_initial.py
2. migrate
wykonuje przepis na bazie danych (tworzy tabele w db.sqlite3) 

python manage.py makemigrations
python manage.py sqlmigrate booking 0001   # podgląd wygenerowanego SQL
python manage.py migrate
📌 Pliki migrations/*.py commitujemy do gita · Plik db.sqlite3 jest w .gitignore (baza lokalna)

ORM w python manage.py shell

W Django 6 modele z booking importują się w shell automatycznie!


cbt = Specialization.objects.create(name="Terapia poznawczo-behawioralna")
dzieci = Specialization.objects.create(name="Psychologia dziecięca")
pary = Specialization.objects.create(name="Terapia par")

anna = Specialist.objects.create(
    first_name="Anna", last_name="Nowak", mode="online", price=200
)
anna.specializations.add(cbt, pary)

Specialist.objects.all()
Specialist.objects.filter(mode="online")

Specialist.objects.filter(price__lte=200)
Specialist.objects.order_by("price")
anna.specializations.all()
pary.specialists.all()          # dzięki related_name="specialists"

Panel administracyjny /admin/

Konto administratora


python manage.py createsuperuser
🔒 Podczas wpisywania hasła w terminalu nie pojawiają się żadne znaki ani gwiazdki.
Wpisz hasło „w ciemno” i naciśnij Enter.

Uruchom python manage.py runserver → zaloguj się na http://127.0.0.1:8000/admin/

Rejestracja modeli w booking/admin.py


from django.contrib import admin

from .models import Specialist, Specialization

admin.site.register(Specialization)
admin.site.register(Specialist)
Odśwież /admin/ → w sekcji BOOKING widzisz swoich specjalistów i specjalizacje z shell!
