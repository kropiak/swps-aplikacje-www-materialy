Część 2

venv i pip

Po co środowisko wirtualne?

📦 Projekt A
Django 6.1
rich 15
📦 Projekt B
Django 4.2
pandas

Każdy projekt ma własne pudełko z bibliotekami → brak konfliktów.

1 projekt = 1 folder = 1 .venv

Tworzenie i aktywacja

🪟 Windows 

python -m venv .venv
.venv\Scripts\Activate.ps1
🍎 macOS 

python3 -m venv .venv
source .venv/bin/activate

Widzisz (.venv) na początku linii? 🎉 Od teraz wszędzie python.

🪟 „running scripts is disabled” → Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

pip: instalujemy bibliotekę


python -m pip install --upgrade pip
pip install rich
pip list
pip freeze > requirements.txt
requirements.txt = przepis na środowisko.
Odtworzenie: pip install -r requirements.txt

Pierwszy skrypt: hello.py


from rich.console import Console
from rich.table import Table

console = Console()
table = Table(title="Nasi specjaliści (dane fikcyjne)")
table.add_column("Imię")
table.add_column("Nazwisko")
table.add_column("Specjalizacja")

table.add_row("Anna", "Nowak", "Terapia CBT")
table.add_row("Piotr", "Wiśniewski", "Psychologia dziecięca")
console.print(table)

# pełna wersja w instrukcji 👉 labs/lab-01
✅ Punkt kontrolny 2: python hello.py wyświetla tabelę

VS Code i git

VS Code: konfiguracja

  1. Instalacja (🪟 ☑️ Add to PATH, 🍎 Install 'code' command)
  2. Rozszerzenie Python (Microsoft)

Instalacja i konfiguracja

🪟 Windows

git-scm.com → Git for Windows
edytor: VS Code
gałąź domyślna: main

🍎 macOS

git --version
→ instalacja Command Line Tools


git config --global user.name "Imię Nazwisko"
git config --global user.email "twoj@email.pl"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"
git config --global core.autocrlf true    # 🪟  (🍎: input)

Trzy miejsca w gicie

📝 folder roboczy
git add →
📋 poczekalnia
git commit →
📸 historia

git status · git diff · git log --oneline: zawsze możesz zapytać, co się dzieje

Pierwsze repozytorium


git init
git status                  # o nie, .venv!
# tworzymy .gitignore z wpisem .venv/
git add .gitignore
git commit -m "Dodaj .gitignore"
git add hello.py requirements.txt
git commit -m "Dodaj skrypt powitalny i listę zależności"
git log --oneline

Ćwiczenie: cykl zmiany

  1. Dodaj specjalistę w hello.py
  2. git status → modified
  3. git diff → co dokładnie?
  4. git add hello.py
  5. git commit -m "Dodaj specjalistkę Ewę Lis"

To samo w VS Code: panel Source Control (Ctrl/Cmd + Shift + G)
